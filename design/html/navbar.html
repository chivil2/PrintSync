PrintSync Dashboard

This is a standalone HTML+CSS replica of the PrintSync navbar. The design uses DM Sans typography, a brand-orange accent color (#F47C3C), and a clean white top bar with subtle border and sticky positioning.

The navbar includes a logo area, three navigation links (Dashboard, Store, View Orders) with an active tab indicator, a cart button with a badge count, and a user dropdown menu with profile, settings, and logout options.
